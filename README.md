# Marketing Vision · Landing page (versão Brasil)

Landing page da Marketing Vision para vender o serviço de landing page no Brasil.
Publicada na Vercel: https://marketing-vision-br.vercel.app

Arquivos: `index.html`, `styles.css`, `app.js` (interações) e `models.js` (modelos da galeria).

Configurações no topo do `index.html`:
- `window.CONTACT.whatsapp`: WhatsApp da agência com DDI e DDD, só números (ex.: 5562999999999)
- `window.ASSET_BASE`: por enquanto as imagens e vídeos vêm da versão americana (test-sites-portfolio.vercel.app)
